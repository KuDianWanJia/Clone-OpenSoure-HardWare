# <center> SDK获取 </center>

[[toc]]

## SDK地址

配套SDK：[https://gitee.com/kodo-rockchip/KODO-RV1106GX-IPC-SDK](https://gitee.com/kodo-rockchip/KODO-RV1106GX-IPC-SDK)

## 克隆SDK

输入如下指令克隆SDK, 并递归克隆子模块：
```shell:line-numbers
git clone --recurse-submodules https://gitee.com/kodo-rockchip/KODO-RV1106GX-IPC-SDK.git
```
