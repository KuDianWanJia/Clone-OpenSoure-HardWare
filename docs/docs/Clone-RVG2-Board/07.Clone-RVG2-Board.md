## 获取源码

案例源码地址： [便携摄像机](https://gitee.com/kodo-rockchip/clone-cardv-lvgl)

案例源码仓库作为 SDK 的子模块，可以在克隆 SDK 时一起拉取(添加`--recurse-submodules`递归拉取子模块)：
```shell:line-numbers
git clone --recurse-submodules https://gitee.com/kodo-rockchip/KODO-RV1106GX-IPC-SDK.git
```

也可以单独拉取案例源码，首先进入 SDK 编译的根目录：
```shell:line-numbers
cd Clone-RVG2-BOARD/rv1106-ipc-linux-v1.8.3-20241009/
```
克隆 `便携摄像机`案例：
```shell:line-numbers
git clone https://gitee.com/kodo-rockchip/clone-cardv-lvgl
```

## 编译案例

导出编译工具链:
```shell:line-numbers
cd Clone-RVG2-BOARD/rv1106-ipc-linux-v1.8.3-20241009/
source envsetup.sh
```

编译 `便携摄像机`案例：
```shell:line-numbers
cd clone-cardv-lvgl/CardvUI/source/Cardv/
make all -j8
make install
```

## 打包案例

打包`便携摄像机`案例到 OEM 分区：
```shell:line-numbers
cd clone-cardv-lvgl/CardvUI/source/Cardv/
make install
```

## OEM 固件打包

进入 SDK 编译目录:
```shell:line-numbers
cd Clone-RVG2-BOARD/rv1106-ipc-linux-v1.8.3-20241009/
```

打包 OEM 分区固件:
```shell:line-numbers
./build.sh firmware
```

打包好的固件位于 SDK 的`Clone-RVG2-BOARD/rv1106-ipc-linux-v1.8.3-20241009/output/image`目录下，重新烧录固件即可在板端的`/oem/usb/bin`目录下找到可执行文件运行。

## 运行案例

运行 `便携摄像机`案例:
::: warning 警告
案例运行依赖摄像头和显示屏, 需提前连接摄像头和显示屏, 否则会报错退出。
:::
```shell:line-numbers
/oem/usr/bin/clone-cardv-lvgl &
```
