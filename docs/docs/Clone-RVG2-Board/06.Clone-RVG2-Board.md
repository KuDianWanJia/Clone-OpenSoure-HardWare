## 获取源码

案例源码地址： [小智AI](https://gitee.com/kodo-rockchip/clone-chatbox-xiaozhi)

案例源码仓库作为 SDK 的子模块，可以在克隆 SDK 时一起拉取(添加`--recurse-submodules`递归拉取子模块)：
```shell:line-numbers
git clone --recurse-submodules https://gitee.com/kodo-rockchip/KODO-RV1106GX-IPC-SDK.git
```

也可以单独拉取案例源码，首先进入 SDK 编译的根目录：
```shell:line-numbers
cd Clone-RVG2-BOARD/rv1106-ipc-linux-v1.8.3-20241009/
```
克隆`AI 小智`案例：
```shell:line-numbers
git clone https://gitee.com/kodo-rockchip/ConversationalAI-Embedded-Kit-2.0
```

## 编译案例

导出编译工具链:
```shell:line-numbers
cd Clone-RVG2-BOARD/rv1106-ipc-linux-v1.8.3-20241009/
source envsetup.sh
```

编译`AI 小智`案例：
```shell:line-numbers
cd chatbox-xiaozhi-1.0.0/
./build-rv1106.sh clean
./build-rv1106.sh all
./build-rv1106.sh install
```

## 打包案例

打包 `AI 小智`案例到 OEM 分区：
```shell:line-numbers
cd chatbox-xiaozhi-1.0.0/
./build-rv1106.sh install
```

## OEM 固件打包

进入 SDK 编译目录:
```shell:line-numbers
cd Clone-RVG2-BOARD/rv1106-ipc-linux-v1.8.3-20241009/
```

打包 OEM 分区固件:
```shell:line-numbers
./build.sh firmware
```

打包好的固件位于 SDK 的`Clone-RVG2-BOARD/rv1106-ipc-linux-v1.8.3-20241009/output/image`目录下，重新烧录固件即可在板端的`/oem/usb/bin`目录下找到可执行文件运行。

## 运行案例

`AI 小智`案例运行前需要联网, 连接 wifi 命令：
```shell:line-numbers
连接 wifi名称:CloneRVG2 wifi密码:12345678 示例：
wifi_start.sh CloneRVG2 12345678
```

运行 `AI 小智`案例:
::: warning 警告
运行该案例需要先连接 wifi, 否则会报错退出。

案例运行依赖摄像头和显示屏, 需提前连接摄像头和显示屏, 否则会报错退出。
:::
```shell:line-numbers
/oem/usr/bin/chatbox-xiaozhi &
```
