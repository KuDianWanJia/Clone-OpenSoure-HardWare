# <center> 环境搭建 </center>

[[toc]]

## 安装虚拟机

在Windows上安装VirtualBox，下载地址：[VirtualBox](https://www.virtualbox.org/wiki/Downloads)

在Windows上安装VMware Workstation，下载地址：[VMware Workstation](https://www.vmware.com/products/workstation-pro.html)

安装完虚拟机后，下载Ubuntu并导入虚拟机，下载地址：[Ubuntu Desktop](https://ubuntu.com/download/desktop)

## 安装Docker

Ubuntu安装完成并启动, 执行如下指令安装Docker：

```shell:line-numbers
sudo apt-get install docker.io
```
确认Docker安装成功：
```shell:line-numbers
docker -v
```
打印类似如下信息说明Docker安装成功：
```
Docker version 20.10.23, build 5003322
```

## 加载Docker镜像

Docker镜像可在资料包获取`docker-clone-18.04.tar.gz`, 执行如下指令加载镜像：
```shell:line-numbers
tar -zxvf docker-clone-18.04.tar.gz
sudo docker load -i docker-clone-18.04.tar
```

查看镜像是否加载成功:
```shell:line-numbers
sudo docker images
```
打印如下信息说明镜像加载成功：
```
REPOSITORY          TAG                 IMAGE ID            CREATED             SIZE
docker-clone        18.04               1306b2133fbd        5 weeks ago         940MB
```

## 创建并运行容器
::: tip Docker Run指令

sudo docker run --rm --privileged -w /home/sgs -it -v /home/user/sdk:/home/sgs  /bin/bash

`--rm: 退出容器时自动清理`

`--privileged: 特权模式`

`-w /home/sgs: 指定默认工作目录(随便创建一个目录，如/home/kodo/Rockchip/Docker)`

`--v /home/user/sdk:/home/sgs: 挂载主机SDK路径到容器(-v  sdk根目录:docker工作目录)`
:::

例如：
```
SDK根目录为:/home/kodo/Rockchip/RV1106BGX-IPC-SDK
Docker工作目录为:/home/kodo/Rockchip/Docker
```
::: warning 注意
1.运行Docker容器前, 需要先拉取SDK, 拉取下来的SDK目录即为前面的SDK根目录:
```
git clone --recurse-submodules https://gitee.com/kodo-rockchip/KODO-RV1106GX-IPC-SDK.git
```
2.可自定义创建一个空目录作为Docker工作目录, 例如:/home/kodo/Rockchip/Docker

:::

执行如下指令运行Docker容器：
```shell:line-numbers
sudo docker run --rm --privileged -w /home/kodo/Rockchip/Docker -it -v /home/kodo/Rockchip/KODO-RV1106GX-IPC-SDK:/home/kodo/Rockchip/Docker docker-clone:18.04 /bin/bash
```
