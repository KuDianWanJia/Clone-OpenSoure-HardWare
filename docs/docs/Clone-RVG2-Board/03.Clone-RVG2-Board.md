# <center> SDK编译 </center>

[[toc]]

## SDK编译

进入 SDK 编译目录：
```shell:line-numbers
cd Clone-RVG2-BOARD/rv1106-ipc-linux-v1.8.3-20241009/
```
编译：
```shell:line-numbers
./build.sh
```
首次编译会自动显示板级配置文件选择菜单，如下：
<div align="center">
  <img width="800" src="/images/Clone-RVG2-Board/03/image.png" />
</div>

开发板对应的配置文件为`BoardConfig_IPC/BoardConfig-SPI_NAND-NONE-RV1106-KODO-RV1106GX-BOARD.mk`，所以选择`4`后再回车：
<div align="center">
  <img width="800" src="/images/Clone-RVG2-Board/03/image2.png" />
</div>

需要重新选择板级配置文件时，可执行：
```shell:line-numbers
./build.sh lunch
```
选择完成后再执行 `build.sh` 进行SDK全量编译：
```shell:line-numbers
./build.sh
```

编译完烧录固件位于`Clone-RVG2-BOARD/rv1106-ipc-linux-v1.8.3-20241009/output/image`目录。
